## 进度
本机浏览器 localStorage 自动保存（不要求登录）。不同浏览器/域名无法直接互读 localStorage，因此原三个网站各自的本地进度不会在新域名自动出现。
新站可导出/导入 JSON 存档。旧版站点导出的进度 JSON（包括各自的答题、错题、收藏）也可导入，导入会合并原记录，不清空新记录。
云同步：电脑、手机、iPad 使用同一组至少 12 位同步码，点击「读取并同步」；同步码用于 PBKDF2/AES-GCM 加密，云端记录键为 SHA-256 摘要。请不要忘记同步码；记录不能凭邮箱恢复。建议用「生成同步码」获得高强度随机值，保存到可信的密码管理器。请勿共享同步码。所有设备可手动点击「读取并同步」合并历史；打开已绑定设备时也会读取云端；新答题通常会自动上传。
